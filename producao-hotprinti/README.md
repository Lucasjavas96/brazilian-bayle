# Estampas Brazilian Bayle - entrega para Javas

## Comece aqui

1. Escolha a estampa pelo nome na tabela abaixo.
2. Abra o README da pasta: ele aponta o arquivo de cada cor.
3. Confira os mockups antes de cadastrar. Fotografias nao sao arquivos de impressao.

## Pastas

- `01-original`: fonte original preservada.
- `02-variantes`: negativas/contraste, com cor no nome do arquivo.
- `historico-nao-usar`: versoes substituidas. Nao cadastrar.
- `frente-papagaio`: logotipo para frente; separado das costas.
- `revisao-visual`: comparacoes de conferencia; nao imprimir.

**PREPARAR FUNDO** indica fonte opaca. Nao cadastrar como PNG transparente sem preparar a matriz.
Os IDs antigos (Thay etc.) estao no README de cada produto e no manifesto.

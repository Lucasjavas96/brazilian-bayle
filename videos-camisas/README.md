# Vídeos das camisas (loja)

Camisa "fantasma" (manequim invisível) em estúdio cinza claro, feita com IA a partir dos mockups da pasta `../mockups` e das artes de `../estampas-costas`. Sem Blender.

## `andando/` (estilo aprovado pelo Gab)
A camisa vem andando até a câmera, vira e mostra as costas. 8 s, em loop, 1080×1080, sem áudio.
- `NN-nome-andando-1080.mp4`: use este na loja (cerca de 1 MB). Tag sugerida: `<video autoplay muted loop playsinline>`.
- `NN-nome-andando.webp`: versão animada tipo GIF (720×720, 1,3 a 1,9 MB) para onde não entra vídeo.

## `fotos/`
Fotos estáticas de manequim invisível. `frente.jpg` serve para todas (a frente é igual: papagaio no peito). `NN-nome-costas.jpg` é a costas de cada camisa.

## `giro/`
Keep Following girando da frente para as costas e voltando (10 s, loop).

## `giro-arrastar/`
Foto que gira sozinha e que o cliente controla arrastando com o dedo ou mouse. São 61 quadros WebP (menos de 1 MB) trocados conforme o arraste. Abra `teste.html` para ver. Por enquanto só a Keep Following; as outras precisam do vídeo de giro.
